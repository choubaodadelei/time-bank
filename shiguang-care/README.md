# 时光养老 · 网页系统

依据用户提供的《时光养老——寄出跨越千山万水的爱》项目材料制作的中文静态网页系统，可部署到 GitHub Pages。无需安装依赖，无需编译，所有资源使用相对路径。

## 部署到 GitHub Pages

1. 在 GitHub 新建仓库，例如 `shiguang-care`。
2. 将本文件所在目录内的文件上传到仓库根目录：`index.html`、`style.css`、`app.js`、`assets` 文件夹和 `.nojekyll`。不要只上传 ZIP，也不要额外套一层文件夹。
3. 打开仓库 **Settings → Pages**。
4. 在 **Build and deployment** 中选择 **Deploy from a branch**，分支选择 `main`，目录选择 `/ (root)`，保存。
5. 等待部署完成，在 Pages 页面打开网站链接。通常为 `https://你的用户名.github.io/shiguang-care/`。

本地预览：双击 `index.html`，或在目录运行 `python -m http.server 8080`，访问 `http://localhost:8080`。推荐使用 HTTP 预览以确保各浏览器存储行为一致。

## 已实现

- 首页：时间余额、待办服务、关怀对象、近期安排。
- 服务预约：六类服务、类别筛选、搜索、日期和地点校验、时间扣除、取消返还。
- 时间账户：收支明细、JSON 数据导出。
- 家属关怀：演示人物、生活记录、本机留言。
- 志愿服务：报名、模拟完成、一次性时间入账。
- 手机适配、大字模式、键盘焦点、表单标签与弹窗。
- localStorage 自动保存，刷新后保留操作。

## 使用范围

这是可部署和交互的前端演示系统，不是已接入真实运营的养老平台。没有后台、登录鉴权、跨设备同步、支付提现、真实派单、消息发送、医疗设备、实时定位或紧急报警服务。不要输入真实住址、身份信息或健康资料。清理浏览器站点数据会清除记录；演示不适合直接承载真实业务数据。

项目材料中的“时间互助、居家服务、家属互动、医食行情用”被转化为页面与交互。原材料中历史统计、财务预测、银行/货币相关表述未作为运营事实发布。时间余额、服务兑换规则、人物和任务均为体验示例；原材料提出的会员费、提现与购买时间机制未接入。本网站不包含原 PDF，以免将材料中的非公开信息一起发布到公开仓库。

## 文件说明

- `index.html`：页面外壳及预约表单。
- `style.css`：设计系统、响应式样式和大字模式。
- `app.js`：服务数据、页面渲染、交互、存储。
- `assets/companionship.png`：AI 生成亲情主题图片，仅作情境展示。

文案与服务配置可在 `app.js` 中修改；颜色与字号在 `style.css` 中修改。无第三方运行时 CDN，不依赖外部字体或图片服务。
